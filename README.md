# Лабораторная работа №5. Многофайловые проекты. Стандартная библиотека шаблонов

## Описание

Программирование и отладка программ формирования и обработки контейнеров,
комбинации контейнеров. Каждое задание реализуется в виде **многофайлового
проекта**:
- объявления структур данных и функций — в заголовочном файле `.h`;
- реализация функций — в отдельном `.cpp`;
- `main.cpp` содержит только точку входа и цикл обработки пользовательского
  ввода; логика обработки в нём запрещена.

Используются только контейнеры и структуры STL, все циклы —
**range-based for**. Нумерация для пользователя — с единицы.

## Задания

**Задание 1. Учёт товаров на складе.**
Адрес ячейки: `<зона><стеллаж><секция><полка>`, например `А1739`
(зона `А/Б/В`, стеллаж `17`, секция `3`, полка `9`). В ячейке — только
один вид товара, не более 10 единиц. Конфигурация склада — по варианту
(таблица 1 методички).

Команды:
- `ADD <товар> <количество> <адрес>` — добавить товар;
- `REMOVE <товар> <количество> <адрес>` — списать товар;
- `INFO` — загруженность склада и каждой зоны (в %, 2 знака),
  заполненные ячейки, список пустых адресов.

**Задание 2. Вариант 1. Электронная очередь в поликлинике.**
На входе — количество окон. Команды:
- `ENQUEUE <минуты>` — добавить посетителя, выдать талон `T001`, `T002`, …;
- `DISTRIBUTE` — распределить очередь по окнам так, чтобы суммарное
  время было минимальным (при равенстве — окно с меньшим номером).

После распределения вывести для каждого окна сумму времени и список
талонов в порядке назначения.

**Задание 3. Многофайловый проект с `enum class` (C++).**
По варианту из таблицы 2 реализовать систему хранения и обработки
информации (графики движения транспорта / линии метро и т.п.).
Все команды хранить в `enum class Type { ... }`. Пример набора
команд для трамваев: `CREATE_TRAM`, `TRAMS_IN_STOP`, `STOPS_IN_TRAM`,
`TRAMS`.

**Задание 4. Вариант 3. Комбинация контейнеров — расписание занятий.**
Многофайловый проект для работы с расписанием студентов. Команды:
- `CLASS <день> <дисциплина>` — добавить дисциплину в день текущего месяца;
- `NEXT` — перейти на следующий месяц (пары сохраняются по дням,
  несуществующий день переносится на последний день месяца);
- `VIEW <день>` — вывести дисциплины дня.

Отсчёт месяцев — с января. Количество дней:
- февраль — 28;
- январь, апрель, июнь, август, октябрь, декабрь — 30/31 (см. методичку);
- март, май, июль, сентябрь, ноябрь — 31/30.

Придумать минимум 5 тестов с разными значениями, в том числе
повторяющимися.
